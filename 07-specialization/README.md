# 专项:模型训练与 GPU 系统(选修)

> [🏠 返回主页](../README.md)

本部分是**选修专项**,不是所有前线部署工程师(FDE)的必修课。很多 FDE 的日常是集成、权限、评测和交付,不写 CUDA,也不微调基座模型。当岗位要在客户预算内做监督微调(SFT)、适配器或推理服务时,才需要这里的深度。

第 3 章已经覆盖检索增强生成(RAG)、工作流和评测。专项从那一章停下的地方继续:硬件如何执行计算,权重如何被低秩更新,训练状态为什么占内存,以及服务延迟和容量怎样从第一性原理估算。

## 怎样读

| 章 | 内容 | 你可以跑什么 |
|---|---|---|
| [第 8 章 GPU 与 CUDA](08-cuda/README.md) | 执行模型、访存、归约、分块矩阵乘、占用率与屋顶线 | CPU 上的事务计数、占用率和参考内核;`.cu` 需 NVIDIA GPU |
| [第 9 章 模型微调](09-finetuning/README.md) | 提示、RAG、SFT、LoRA、QLoRA 的适用边界和训练配方 | 标准库测试;有依赖时在 CPU 上训练微型 GPT-2 |
| [第 10 章 训练优化](10-training/README.md) | 内存账、混合精度、累积、检查点、打包、DDP/FSDP/ZeRO | 纯计算测试 |
| [第 11 章 推理优化](11-inference/README.md) | 预填/解码、KV cache、组批、量化、投机解码、压测方法 | 排队模拟和字节账,不是 GPU 基准 |

## 数字怎么读

- **恒等式和模型**会给出确切字节数或闭式结果,并写明假设。这些不是 profiler 读数。
- **假设情景**里的峰值算力、带宽、单价和时延是输入,用来练习判断算力顶还是带宽顶。它们不是某张显卡的铭牌,也不是一次实验的加速比。
- 本仓库**不记载未测量的加速倍数**。CUDA 示例如果在你的机器上打印了毫秒数,那个数只属于那次进程和那块 GPU。

## 在本仓库验证

无 GPU、不下载模型的测试:

```bash
python3 07-specialization/run_tests.py
```

微型 LoRA 还需要 [requirements-cpu.txt](09-finetuning/examples/requirements-cpu.txt) 里的 CPU 依赖。没有这些包时,对应测试会跳过,其余测试仍应通过。

## 编写环境的局限

编写本专项时的环境没有 `nvidia-smi` 和 `nvcc`,因此:

- `08-cuda/examples` 下的 CUDA 程序**没有编译,也没有在 GPU 上运行**。正确性由与之对应的 Python 参考实现锁住;源码里的错误检查、预热和 `cudaEvent` 计时需要你在有 GPU 的机器上执行。
- QLoRA、bitsandbytes、vLLM 和 Nsight **没有安装,也没有运行**。
- 微调脚本只用随机初始化的微型 GPT-2 和虚构制度文本,在 CPU 上走通一步。打印出的损失不是模型质量。
