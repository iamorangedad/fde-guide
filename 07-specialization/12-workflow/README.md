# 第 12 章 端到端专业流程与综合案例

> [🏠 返回主页](../../README.md) · [返回专项](../README.md)

本章把第 8–11 章收成一条可以交付的工作顺序。它仍然是专项:不做模型训练或推理容量的 FDE 项目,用第 1–4 章的集成、安全和范围说明书就够了。本章的综合案例是虚构的澄海仓储,预算和延迟都是题目中的给定,不是测量。

## 先修

第 4 章的范围说明书,第 9–11 章的公式。不要求先把 CUDA 写完,但案例里的字节账默认你接受那些公式的前提。

## 学习目标

- 按"基线 → 瓶颈 → 假设 → 单变量实验 → 正确性与质量门 → 发布与回滚"写一份计划
- 拒绝把两个因素绑在同一次实验里
- 为一个带资源预算和验收标准的客户需求做出可复核的设计,并标明哪些数还没有测
