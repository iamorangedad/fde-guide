# 第 5 章 作品集项目

> [🏠 返回主页](../README.md)

每个项目都应模拟"客户交付":写范围说明书、交付代码、写 Runbook、录 5 分钟演示视频、写复盘。

| # | 项目 | 能力 | 周期 |
|---|---|---|---|
| P1 | 多源数据整合与看板 | 集成、SQL、建模 | 2 周 |
| P2 | 企业知识库 RAG(带权限) | RAG、评测、安全 | 3 周 |
| P3 | 文档抽取工作流 | LLM 结构化输出、人工审核 | 2 周 |
| P4 | 工具调用 Agent | Agent、追踪、护栏 | 2 周 |
| P5 | 私有化部署包 | Docker、IaC、可观测性 | 1–2 周 |

## P1 多源数据整合与看板
- **目标**:整合公开数据集(如城市开放数据)中的 2–3 个来源,构建统一模型与看板
- **规格**:增量拉取、幂等 upsert、数据质量测试、新鲜度监控
- **里程碑**:W1 原始层+staging;W2 marts+看板+告警
- **验收**:重跑无重复;质量测试全部通过;README 能让他人 30 分钟内跑起来
- **扩展**:CDC、SCD2

## P2 企业知识库 RAG
- **目标**:对一组公开文档构建问答系统,模拟三种角色权限
- **规格**:混合检索、重排序、引用来源、检索时权限过滤、≥50 条评测集
- **验收**:报告召回率@5 与忠实度;越权测试 0 泄露;错误分析文档
- **扩展**:查询改写、多轮对话

## P3 文档抽取工作流
- **目标**:从发票/简历等 PDF 抽取结构化字段
- **规格**:Pydantic 校验、低置信度转人工审核界面、字段级准确率评测
- **验收**:有标注集与准确率报告;失败可追溯
- **扩展**:主动学习,收集人工更正

## P4 工具调用 Agent
- **目标**:运营助手,可查询数据库、生成报告、创建工单(模拟)
- **规格**:工具参数校验、最大步数、写操作需人工确认、全链路追踪
- **验收**:20 个场景测试用例;提示注入测试用例
- **扩展**:多 Agent 编排

## P5 私有化部署包
- **目标**:把 P2 打包为可在"客户环境"一键部署
- **规格**:Docker Compose 或 Helm、Terraform、健康检查、日志/指标、Runbook、离线安装说明
- **验收**:在干净虚拟机上按文档 1 小时内完成部署

## P6(选修)制度助手的容量与发布计划
- **对应**:[第 12 章](../02-ai-llm/12-workflow/README.md)。不做模型训练的岗位可以不做 P6
- **目标**:为一个虚构的内部问答需求写出范围、资源预算、基线和只含一个自变量的实验
- **规格**:知识走 RAG;全量微调若被排除,要给出第 10 章的字节账;延迟门使用 TTFT/p95 的定义;GPU 上没跑的项写入未测清单
- **验收**:`gates.py` 的结构检查通过;每个数字能指回仓库里的函数;没有未测的加速比

## 评分标准(每项 1–5)
问题定义清晰度 / 工程质量 / 评测严谨性 / 文档与可交付性 / 演示表达
