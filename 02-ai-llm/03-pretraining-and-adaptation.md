## 学习目标

- 区分预训练、继续预训练（CPT）、指令微调与对齐各自优化的「分布」
- 判断客户语料适合 RAG、CPT 还是根本不该进训练
- 能写出因果语言建模损失的概念形式，并知道实现细节指向何处

## 定义

**预训练（pretraining）**：在大规模无标注（或弱标注）文本上学习通用的下一个 token 预测（或其他自监督目标），得到基座模型。公开报道中的大规模预训练属于平台级工程；FDE 交付极少从零做起。

**继续预训练 / 领域自适应预训练（continued pretraining, CPT）**：在基座上继续用领域语料做同类自监督目标，使 token 分布贴近领域（术语、写法、代码方言），**不**直接优化「按用户指令回答」。

**指令微调 / 监督微调（SFT）**：用「指令 → 期望回答」配对，优化条件分布 \(p(\text{回答}\mid\text{指令})\)。见 [3.4](04-finetuning-and-alignment.md)。

**对齐（alignment）**：在 SFT 之后，用偏好或奖励信号进一步塑造风格、安全与推理行为（RLHF、DPO、GRPO 等），亦见 3.4。

直觉口诀：**预训练学「语言与世界的统计」；SFT 学「如何按格式做事」；对齐学「在多种可行答法里更偏好哪一种」。** 事实会变的知识仍应优先外置（RAG）。

## 原理：因果语言建模（概念）

解码器模型把序列 \(x_1,\ldots,x_T\) 的联合概率写成：

$$
p_\theta(x)=\prod_{t=1}^{T} p_\theta(x_t\mid x_{<t})
$$

（实现上常从 \(t=2\) 起，对第一个 token 无预测；移位与 `ignore_index` 的精确约定见 [3.4](04-finetuning-and-alignment.md) 与 [3.6](06-pytorch-engineering.md)。）

训练最小化平均负对数似然（NLL）：

$$
\mathcal{L}_{\mathrm{CLM}}(\theta)=-\mathbb{E}_{x\sim\mathcal{D}}\sum_{t}\log p_\theta(x_t\mid x_{<t})
$$

**CPT 与 SFT 可以共用这一损失形式**，差别在数据与掩码：

| | 数据 | 通常掩码 |
|---|---|---|
| 预训练 / CPT | 连续文档、代码、网页清洗结果 | 几乎所有 token 参与损失 |
| SFT | 对话或指令模板 | 常屏蔽提示，只对回答计损失 |

把制度条文拿去 CPT，模型更可能「续写得像制度」，**不保证**会按员工角色正确拒答或引用章节号；后者要 RAG + 评测，必要时再 SFT 格式。

### 何时考虑 CPT（业务清单）

同时接近「是」才慎重评估：

1. 领域文本量大，且与通用网页分布明显不同（内部 DSL、法规体例、专有缩写密集）；
2. RAG 已做好仍系统性「读不懂」领域句式（不是检索不到）；
3. 有可持续的数据清洗、去污、许可与去重流程；
4. 有可复现的领域评测（不是只看训练 loss）；
5. 算力与人时预算允许，且接受基座升级时要重做 CPT 的成本。

**不要 CPT 的常见情况**：手册月更、强 ACL、答案必须可点击溯源——这些是 RAG；只有「口吻/字段」不稳——这是 SFT；只要「更客气/更拒绝」——这是对齐或规则。

### 数据质量（概念层）

预训练语料工程通常包括：去重、语言识别、质量过滤、个人与机密信息剥离、许可证合规。DeepSeekMath 等工作强调：**领域能力很大一块来自继续预训练的数据选型**，而不只是最后的 RL 公式（见延伸阅读）。本稿不复述未核验的基准分数；你若引用某篇论文数字，请打开原文核对设定。

## 演算（可复现、无模型）

均匀随机词表大小 \(V\) 时，每个位置的期望 NLL 约为 \(\log V\)。若 \(V=50257\)（GPT-2 词表规模，公开模型卡常见取值），则 \(\log 50257\approx 10.825\) nat。训练 loss 降到「大约这个数」附近，只说明「略好于瞎猜」，**不是**任务学会了。脚本：`examples/worked_examples.py` 中的 `clm_uniform_nll`。

## 案例（虚构）

某芯片公司希望模型「懂」内部 netlist 文本。通用模型把信号名当英文乱拆。团队先做了专用分词与语法高亮解析进 RAG，失败率下降；仍不够时，才用脱敏 netlist 做小规模 CPT，并用「语法合法率 + 人工抽检」评测。他们**没有**把工艺参数表 CPT 进模型，因为参数每周变——参数走数据库工具。

## 练习

1. 用自己的话区分：CPT 损失下降、SFT 损失下降、线上采纳率上升——三者分别证明了什么，不能证明什么？
2. 客户有 2 万页 PDF 制度 + 每天变更的价格表。哪些进索引，哪些绝不应作为 CPT 主粮？为什么？
3. 为什么说「我们把公司所有邮件拿去预训练」在合规与效果上都很危险？列出至少三点。

### 参考解答

1. CPT loss↓：领域续写更像训练语料，不证明问答正确；SFT loss↓：更拟合标注回答，可能过拟合标准答案措辞；采纳率↑：接近业务价值，但仍需分解错误类型。
2. 制度与价格表主体进带权限与时效元数据的索引；价格表尤其要工具/DB。CPT 若做，也只考虑长期稳定的体例/术语文本，并严格脱敏。
3. 隐私与劳动合规；邮件噪声与个人攻击会被学进分布；时效与权限无法进权重；难以评测与回滚。

## 小结

预训练与 CPT 改的是「语言分布」，不是「可审计的企业事实」。概念上先锁定目标与数据边界；公式实现与算力账往后读。
