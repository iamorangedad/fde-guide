# 成为 FDE(Forward Deployed Engineer,前线部署工程师):系统教程

本仓库是一套教科书式的系统课程,而非单篇文章。每章包含:学习目标、核心概念与定义、原理、实例、图示(Mermaid)、案例、练习(含参考答案或评分标准)、小结、关键术语与延伸阅读(仅收录已核实来源)。

## 适合谁
- 有 1 年以上编程经验、希望转向"工程 + 客户"复合岗位的软件工程师
- 想补齐工程能力的解决方案工程师(SE)、技术咨询顾问、数据分析师
- 计算机相关专业的高年级学生

## 如何使用
1. 先读 `00-overview` 建立对岗位的准确认知;
2. 按 `ROADMAP.md` 的 12 周或 24 周计划推进;
3. 每章练习务必动手;`04-projects` 的作品是求职的核心证据;
4. 面试前两周集中练 `05-interview`;
5. 第 3 章在 `02-ai-llm`。只有岗位涉及模型训练或推理性能时,再读同目录的第 8–12 章;那几章是专项,不是全体 FDE 的必修。

## 学习计划概要
- **12 周(全职强化)**:第 1–2 周概览+集成;3–4 周部署安全;5–7 周 LLM 系统;8 周客户能力;9–11 周项目;12 周面试。
- **24 周(在职)**:每阶段时长翻倍,项目阶段并行进行客户能力练习。
详见 [ROADMAP.md](ROADMAP.md)。第 8–12 章在 `02-ai-llm`,是选修专项,不替换上面的 12 周。
