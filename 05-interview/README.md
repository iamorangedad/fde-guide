# 第 6 章 面试准备

> [🏠 返回主页](../README.md)

## 学习目标
了解常见流程,掌握问题分解面试、编码、项目深挖与行为面试。

## 6.1 常见环节(具体以各公司为准)
招聘方沟通 → 编码(实用型,常涉及数据处理/API)→ **问题分解/案例**(开放业务问题)→ 项目深挖 → 行为/客户场景 → 团队匹配。据公开报道,Palantir 面试包含 decomposition 环节。

## 6.2 问题分解面试
框架:**澄清目标 → 识别用户与指标 → 拆解子问题 → 数据与系统 → MVP → 风险 → 迭代**。
例题:"一家医院希望减少急诊等待时间,你会怎么做?"
参考要点:澄清"等待"定义(到达→分诊→就诊);数据(挂号系统、电子病历时间戳);找瓶颈(分诊人力、床位);MVP(实时排队看板+到达量预测);风险(数据隐私、临床流程变更);指标(中位/P90 等待)。
**评分(1–5)**:结构性、澄清问题质量、数据意识、可落地性、沟通。

## 6.3 编码
重点:字符串/JSON 处理、哈希表、排序、区间、简单图;以及"读 API 分页数据并聚合"这类实用题。练习时边写边说思路,写测试。

## 6.4 行为与客户场景
用 STAR(情境-任务-行动-结果)。准备 6 个故事:处理模糊需求、客户冲突、生产事故、说服他人、失败与复盘、在压力下交付。
模拟场景:"演示前一小时客户数据管线挂了。" 评分:先止损与沟通、透明说明影响、备用方案、事后复盘。

## 6.5 两周冲刺清单
- [ ] 10 道分解题限时 30 分钟,录音复盘
- [ ] 20 道实用编码题
- [ ] 每个作品集项目准备 5 分钟讲解 + 深挖问答
- [ ] 6 个 STAR 故事
- [ ] 2 次完整模拟面试
